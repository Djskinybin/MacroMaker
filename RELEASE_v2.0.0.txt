MacroMaker v2.0.0

Major automation update.

Added:
- Project variables and variable expressions
- Screen, active-window, and relative-to-mouse coordinates
- IF / Wait / Loop variable conditions
- IF / Wait / Loop key conditions
- Find image/color and save found coordinates into variables
- Window IF/focus/minimize/maximize/restore/close actions
- Clipboard and text-file commands
- User text and Yes/No prompts
- Command groups, labels, and enable/disable
- Run From Here, command copy/paste
- Per-command failure handling with retry/stop/fallback sequence
- Macro Setup with project-level runtime settings and user-editable inputs
- Playback speed, HUD position, and HUD opacity controls
- Export project as ZIP

Existing v1.x project folders remain supported.
